# Biznct CRM

Biznct CRM with Kanban boards for sales pipeline and client delivery.

## Features

- **Sales Pipeline**: Track deals from lead to closed
- **Client Delivery**: Manage projects from onboarding to delivery
- **AI Assistant**: Get insights, draft follow-ups, create tasks
- **Dark/Light Mode**: Comfortable viewing in any environment
- **Real-time Sync**: Connected to Supabase for live updates

## Tech Stack

- Next.js 15 + React 19
- TypeScript
- Tailwind CSS
- Supabase
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Deploy to Vercel:

```bash
vercel --prod
```

## Environment Variables

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
